# Using Accounting

This page ships with the __accounting__ addon and is seeded into [{$applicationname}]
when the addon is enabled.

## Enable the addon

```json
{
  "ngdpbase.addons.accounting.enabled": true
}
```

Discovery alone does not enable an addon — the key above is required.

## Plugins

- `[{Accounting}]` — renders the Accounting plugin.

## Editing this page

Once seeded, this page belongs to the instance. Edits made here are preserved:
the addon will not overwrite a page you have changed.
