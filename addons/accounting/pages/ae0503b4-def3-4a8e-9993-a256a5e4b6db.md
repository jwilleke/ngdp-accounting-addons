# Set an Account's Opening Balance

What an account held on the day the books started: the bank statement for a bank account, the
count for Cash on Hand. It is set once and never changes. All accounts added up should equal all
funds; the [Ledger] page says when they do not. The bank accounts themselves are set in the site's
configuration.
