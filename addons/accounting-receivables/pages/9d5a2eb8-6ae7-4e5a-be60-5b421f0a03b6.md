# Invoices

Invoices for each account's charges: one invoice per billing address each month, numbered I-0001 onwards, kept exactly as issued. Invoices are not money: the ledger holds only money that moved. A payment is a receipt (R-number) that names the account.

- [Prepare This Month's Invoices]: what each account owes this month, with any late charges, then issue
- [Record a Payment on an Account]: money an account paid; oldest invoices are settled first
- [Account Balances]: each account's balance, or the credit it has paid ahead
- [Void an Invoice]: an invoice issued by mistake

[{Receivables view='invoices'}]

Open an invoice's number to see or print it. Back to [Accounting], the treasurer's home.
